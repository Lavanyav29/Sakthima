# Sakthima — Full-Stack Website Development Case Study

**Live Website:** https://sakthima.in/

## Project Overview

Sakthima is a live business website developed as a full-stack web application. It includes a public-facing website, product and industry information, enquiry functionality, and an administrative interface for managing website content.

This repository is a documentation-only portfolio case study. It does not contain the client's application source code, screenshots, database exports, credentials, or private assets.

## My Role

**Full-Stack Web Developer**

I handled the end-to-end development of the website, covering frontend and backend implementation, database integration, application functionality, and deployment.

## Responsibilities

- Developed the public-facing website and user interface.
- Implemented backend functionality using Laravel.
- Built administrative modules for content and website management.
- Integrated PostgreSQL database.
- Developed product, category, industry, and certification management.
- Implemented enquiry and customer engagement functionality.
- Implemented authentication and user management.
- Prepared frontend assets for production.
- Deployed the application and made it publicly accessible.

## Key Features

### Public Website

- Home, About, and Contact pages.
- Product catalogue and product detail pages.
- Industry information pages.
- Product search.
- Contact and enquiry forms.
- Newsletter subscription.

### Administrative Interface

- Dashboard and user management.
- Product and category management.
- Industry and certification management.
- Client and leadership content management.
- Hero slide and gallery management.
- Website content and page-section management.
- Updates and video management.
- Customer enquiry management.
- Supplier contact management.
- Activity logs and application settings.

## Technology Stack

| Area | Technology |
|---|---|
| Backend | PHP |
| Framework | Laravel 13 |
| Database | PostgreSQL |
| Frontend | HTML, CSS, JavaScript |
| CSS Framework | Tailwind CSS |
| JavaScript Library | Alpine.js |
| HTTP Client | Axios |
| Asset Build Tool | Vite |
| CSS Processing | PostCSS, Autoprefixer |
| PHP Dependency Manager | Composer |
| JS Dependency Manager | npm |

## Development & Implementation

- Implemented application functionality using Laravel.
- Organized backend functionality using routes and framework conventions.
- Developed public-facing pages and administrative features.
- Integrated PostgreSQL for application data.
- Used Alpine.js for frontend interactivity.
- Managed frontend styling with Tailwind CSS.
- Used Vite for frontend asset compilation and production builds.
